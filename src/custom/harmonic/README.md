# Harmonic Tremolo

Monument V2-inspired harmonic tremolo approximation with original DSP—not a Walrus Audio port.

## Controls

- **Rate**: quarter-note base speed, approximately 0.5–12 Hz.
- **Depth**: tremolo intensity.
- **Shape**: continuous sine → triangle → square → rising-ramp morph. The actual C waveform functions are shared with the host validation program.
- **Volume**: output level; centre is unity, lower settings attenuate and higher settings boost.
- **Division**: named selector for quarter (1×), quarter-note triplet (1.5×), or eighth (2×) rate. Rate sets the free-running base; tap-tempo sync is not implemented.
- **Mode**: named selector for Standard (whole-band amplitude tremolo) or Harmonic (low/high bands modulated oppositely).

The Zoom implementation represents the Monument V2 toggles as named parameter selectors. It does not emulate the physical tap footswitch or a tempo-synchronized external clock. Pedal raw control ranges remain 0–100; the selector labels are generated by the repository's existing selector support, and the control still rotates through those ranges on hardware.

## Build and verification

With TI C6000 CGT and the repository's local linker files installed:

```powershell
$env:TI_CGT_ROOT = 'C:\ti\ti-cgt-c6000_8.5.0.LTS'
python src\custom\harmonic\build.py
```

This produces `dist\Harmonic.ZDL`. Test the exact C waveform implementation on a host compiler from this directory:

```sh
gcc -std=c99 -O2 test_waveform.c -lm -o test_waveform
./test_waveform
```

The test checks sine, triangle, square, and ramp landmarks, all shape morph joins, and 200,301 phase/shape combinations for finite bounded output. It tests waveform math only; it does not validate TI code generation, ZDL loading, or pedal sound/stability.

A successful link is not hardware validation. Confirm the effect ID is unique on the target pedal, back up patches, and have Zoom recovery available before testing.
